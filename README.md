# AI Music Evaluation Research

This repository contains the full research workflow for evaluating an AI-powered
music generation model across 20+ genres. It includes:

- Prompt datasets
- Experimental design
- Objective metrics (FAD, embeddings, rhythm, spectral features)
- Human evaluation protocols (MOS, Pairwise)
- Usability testing
- Analysis scripts
- Research notes and documentation

This repo is used to track progress and maintain reproducibility for the study.
