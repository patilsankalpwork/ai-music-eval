# Project Summary (1-page)

**AI Music Evaluation Benchmark** — a 450-prompt dataset spanning 150 genres to evaluate text-to-music systems across timbre, rhythm, structure, production aesthetics, and cultural fidelity.

Deliverables:
- 450 text prompts in strict CSV schema
- Evaluation rubric (human + automated)
- Validation and analysis scripts
- Documentation for reproducibility and grant applications
